# NHL Draft Analytics Dashboard (1963-2020)

Built an interactive dashboard in Python using Dash and Plotly Express to analyze and visualize NHL statistics spanning 1963–2020. 
## Features
### Draft Performance by Position
Interactive Bar Chart and Scatter Plots featuring goals, asists and points for each position filtered by draft year.
### Age and Performance Breakdown
Radio buttons and dropdowns dynamically update a pie chart showing positional goal distribution by team and draft age.
### Nationality and Games Played Analysis
Interactive Bar chart featuring games played for each position and a slider filtering by draft position.
### Multi Chart with Chained Callback
Coordinated updates across multiple visualizations using Dash Callbacks

## Tech Featured 
* Python
* Pandas
* Dash
* Plotly Express
* Dash Bootstrap Components

## How to Run
To run the dashboard, unzip the folder and open Final Project Dashboard.ipynb in Jupyter. Make sure the data files stay in the same folder.
